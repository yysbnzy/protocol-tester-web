# 协议测试工具后端代码审查报告

**审查时间**: 2026-06-03
**审查范围**: app.py + backend/core/ 全部 12 个模块
**发现总数**: 23 个（严重 5 / 中等 11 / 轻微 7）

---

## 🔴 严重（5个）

### 1. packet_assembler.py — UDP报文构建缺少 IP 层
- **位置**: `build_packet()` UDP 分支
- **问题**: UDP 分支没有 `ip_pkt = IP(dst=target_ip, src=src_ip)`，构建出的报文无 IP 头
- **修复**: 在 UDP 分支补全 IP 层构建

### 2. app.py — ARP 发送时端口校验错误
- **位置**: `/api/send` 路由
- **问题**: `all([protocol, target_ip, target_port])` 要求所有协议都有 target_port，但 ARP/ICMP 不需要端口
- **修复**: 按协议类型分别校验必填字段

### 3. capture_manager.py — 抓包线程异常静默吞噬
- **位置**: `start_capture()` sniff 线程
- **问题**: 异常只记日志，不通知前端，前端显示"开始抓包"但永远无数据
- **修复**: `socketio.emit('capture_error', ...)` 通知前端

### 4. tcp_manager.py — 重连风暴风险
- **位置**: `_reconnect()` 方法
- **问题**: 立即无条件重连，目标不存在时 CPU 极限频率重试
- **修复**: 添加指数退避 `time.sleep(delay)` (1s, 2s, 4s, max 30s)

### 5. send_mode_manager.py — socket 发送异常时未关闭连接
- **位置**: `_send_tcp_socket()` / `_send_udp_socket()`
- **问题**: 异常时 socket fd 泄漏
- **修复**: `with socket.socket(...) as sock:` 或 try/finally

## 🟡 中等（11个）

### 6. config_manager.py — 默认配置全局可变
- **问题**: `get_defaults()` 返回全局 dict 引用，调用方修改影响全局
- **修复**: `return copy.deepcopy(DEFAULT_CONFIG)`

### 7. config_manager.py — 端口 0 被当作有效端口
- **问题**: `validate_port()` 允许端口 0 作为目标端口
- **修复**: 目标端口限制为 1-65535

### 8. capture_manager.py — 报文列表无限增长
- **问题**: `packet_list` 无上限，长时间抓包内存泄漏
- **修复**: 环形缓冲区，最大 10000 条

### 9. stream_manager.py — 流过期机制缺失
- **问题**: TCP/UDP 流创建后永不清理，无 TTL
- **修复**: 添加 `last_activity` + 后台 TTL 清理线程

### 10. display_filter.py — 空值比较逻辑错误
- **问题**: `None`/`-`/`''` 与数字比较时 `float()` 抛异常或意外匹配
- **修复**: 统一 `is_empty(v)` 辅助函数处理空值语义

### 11. npcap_manager.py — 下载标志非线程安全
- **问题**: `self.is_downloading` 是普通 bool，多线程可能重复下载
- **修复**: `threading.Lock()` 保护

### 12. app.py — /api/pcap/download 路径遍历风险残余
- **问题**: Windows 反斜杠 `..\..\` 可能绕过正则
- **修复**: `pathlib.Path(filename).name` + 正则二次校验

### 13. app.py — socket.io connect 事件无异常处理
- **位置**: `@socketio.on('connect')`
- **问题**: 初始化 emit 异常导致客户端连上但收不到数据
- **修复**: try/except 包裹初始化逻辑

### 14. wireshark_dissectors.py — TCP checksum 未验证
- **问题**: 只读取 checksum 字段但不验证
- **修复**: 可选 checksum 验证或标记 "unchecked"

### 15. packet_assembler.py — TCP 序列号简单递增
- **问题**: 每次 build_packet seq + len(payload)，连续发送时序列号跳跃
- **修复**: 按四元组维护独立 seq 计数器

### 16. pcap_exporter.py — 时间戳精度丢失
- **问题**: `time.time()` 秒级浮点数截断为微秒
- **修复**: `time.time_ns() // 1000` 获取微秒级

## 🟢 轻微（7个）

### 17. app.py — 多处 magic number 未命名
- `max_packet_list = 10000` → `MAX_PACKET_LIST_SIZE`
- `MAX_CONTENT_LENGTH = 10 * 1024 * 1024` 硬编码

### 18. config_manager.py — 硬编码 MAC 地址
- `src_mac = "00:11:22:33:44:55"` 使用真实 OUI
- 修复: 改为 `02:00:00:00:00:00` (locally administered)

### 19. npcap_manager.py — Npcap 版本硬编码
- `npcap-1.79.exe` 写死
- 修复: 支持 API 获取最新版本或用户指定

### 20. udp_icmp_sender.py — ICMP payload 截断无警告
- payload > 65507 时静默截断
- 修复: 截断前记录 warning

### 21. send_mode_manager.py — simulate 模式延迟计算错误
- `time.sleep((interval_ms / 1000.0) * min(count, 3))` 语义错误
- 修复: 循环内每次 sleep interval_ms / 1000.0

### 22. display_filter.py — 词法分析器跳过非法字符无反馈
- 未知字符直接 `self.pos += 1`，用户输入错误被静默截断
- 修复: `raise SyntaxError(f"Unexpected character '{char}' at {self.pos}")`

### 23. scapy_sender.py — 未处理 scapy 构建失败
- `build_packet()` 可能返回 None，未检查直接传给 send()
- 修复: `if packet is None: return {'success': False, ...}`
